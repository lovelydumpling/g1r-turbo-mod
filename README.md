# Turbo Mod

## For G1R Recomp, Gens 1, 2, 3

This adds configurable options to bind controller buttons to hold for turbo (autofire) A and/or B. This also adds an option to hold a button to temporarily enable speedup while the button is held.

The speedup includes the same speed rates as available in G1R's game speed options. Once you let go of the button, the game returns to the game speed you have set in your options. 1x is included as an option as well, if you want you can have the inverse, having the game sped up by default but return to normal while holding the button.

By default, no bindings are set. Go to Mods > Turbo Mod > Options to set them. You can press Select to clear them.
